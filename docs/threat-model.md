# Threat model

What the workbench service protects, from whom, and what is still open. Written for the 1.1.0 code;
nobody independent has reviewed it. The lab's own research scope is in
[README: Local operation and evidence boundaries](../README.md#local-operation-and-evidence-boundaries).

## What it protects

| Asset | Where it lives |
|---|---|
| Cases: traces, replayed SQLite databases, reduced witnesses, reports, hash manifests | the data directory (`/data` in the image) |
| Imported real evidence (SQLite/WAL exports, ADB acquisitions) | CLI output folders; never uploaded through the server |
| API keys | callers hold the key; the server holds only SHA-256 hashes |

## Trust boundaries

1. **Browser or script → server.** Traces are untrusted JSON; the server validates them before replay.
2. **Server → filesystem.** Case IDs are generated by the server and resolved inside the data directory.
3. **CLI → custom parser plugins.** Plugins are trusted code by design; the browser can't load them.

## Threats and what stops them

| Threat | Mitigation | Residual risk |
|---|---|---|
| Another site's page drives the local workbench (CSRF, DNS rebinding) | `Host` must be loopback or listed in `ALLOWED_HOSTS`; POSTs with a foreign `Origin` are refused; JSON only | — |
| Someone on the network reads cases or runs experiments | Hashed API keys with roles; production refuses to start without them; no public bind without keys | Every key sees every case (single tenant) |
| Flooding or a long experiment ties up the server | 1 MiB bodies with Content-Length, no chunked bodies, one experiment at a time (409), evaluation budget ≤ 1000, rate limit per client, 15 s socket timeout | One heavy experiment still blocks others by design |
| A crafted trace escapes the case directory or crashes the replay | Trace schema validation; server-generated case IDs; errors become 400 with no stack trace | — |
| A bundle is altered after export | SHA-256 manifest checked by `verify` | The manifest is unsigned: whoever can replace both can forge it |
| Evidence leaks into logs | Access logs are JSON with method, route, status and user only | — |
| A malicious plugin | CLI-only, run in a separate process with a timeout | Not a sandbox: only run trusted plugins |

## Not covered

- Multi-tenant isolation between keys.
- Signed chain of custody.
- TLS (terminate it at the ingress).
